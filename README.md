## このアプリについて

ビニールプールの金魚を、ポイ（和紙を張った輪）ですくうゲームです。

和紙は水にひたすほどぬれ、ぬれているほどやぶれます。ポイは3本。3本めがやぶれたらおしまいで、
**時間制限はありません**。めずらしい色の金魚ほど点が高く、そのぶん重くて和紙がやぶれやすくなります。

すくうとコインがたまり、100枚でポイが1本ふえます。たまに現れるカメ・カニはとても速く、
3匹すくうとボーナスタイムになります。
